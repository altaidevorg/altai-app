# CP-08-13 — Project-scoped durable run-context lookup

**Status:** in progress  
**Backlog package:** 031  
**Depends on:** CP-08-11, CP-08-12

## Outcome

Resolve a requested WorkItem through the target workspace's canonical Project,
then assemble a bounded execution context from durable repositories.

## Invariants

- The caller supplies stable IDs only; it cannot inject renderer-owned work
  text into the context path.
- A missing workspace, missing WorkItem, or cross-project WorkItem fails
  closed.
- This is a read boundary. It deliberately does not introduce a second writer
  or migrate the legacy UI WorkStore implicitly.
