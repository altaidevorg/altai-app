# CP-08-38 — Local `work.db` migration runner

**Backlog package:** 052 — Local migration runner and lifecycle (PR 1 of 2)

## Goal

Give every local host one explicit, idempotent entry point for bringing the
single workspace `work.db` to the current Work OS schema. This is not a second
database and does not introduce a daemon requirement.

## Acceptance evidence

- `LocalMigrationRunner` initializes the core Work store and every current
  local control-plane schema owner before recording its lifecycle checkpoint.
- Reopening the same database is idempotent.
- A database carrying a newer lifecycle version fails closed before adapters
  are opened.
- The runner preserves the secure first-creation behavior of `WorkStore`.

## Follow-up

CP-08-39 wires this runner into app/host startup and verifies rollback
semantics. It must not create a parallel database path.
