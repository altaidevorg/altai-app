# CP-08-16 — Explicit legacy WorkStore projection bridge

**Status:** in progress  
**Backlog package:** 031  
**Depends on:** CP-08-12

## Outcome

Create a one-way, idempotent projection from an existing local WorkStore record
to a selected canonical Project's WorkItem repository.

## Invariants

- The caller explicitly supplies the canonical Project mapping; no filesystem
  name or legacy project ID is silently treated as canonical identity.
- Replaying the same legacy revision is idempotent.
- A changed legacy revision fails closed until an explicit reconciliation and
  writer-ownership package is accepted.
- This bridge never updates legacy WorkStore lifecycle state.
