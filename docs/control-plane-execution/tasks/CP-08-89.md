# CP-08-89 — OpenTag identity/metadata conformance fixture

- **Package:** 083 — OpenTag codebase (PR 2)
- **Status:** in progress
- **Depends on:** CP-08-88, 051 and 071

## Outcome

Implement `OT-083-identity-metadata-v1` as a transport-free ALTAI adapter
contract. It accepts only a provider-verified inbound event, resolves only a
pre-registered active ALTAI agent, projects the requester as `Actor::External`,
allowlists bounded non-secret metadata, and derives a stable correlation id for
redelivery. It creates no Work, Attempt, lease, Activity, Evidence, plugin, or
identity record itself.

## Acceptance

- Unverified sources, unknown/paused agents, unallowlisted metadata and
  credential-like values fail closed.
- Identical redelivery produces an identical correlation and external actor.
- The contract remains transport/database-free; durable idempotency and all
  mutations remain on the existing ALTAI protocol path.
- Focused tests, complete `altai-control-plane` tests and clippy are green.
