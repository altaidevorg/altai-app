# CP-08-14 — Attempt-bound durable run context

**Status:** in progress  
**Backlog package:** 031  
**Depends on:** CP-08-03, CP-08-10, CP-08-13

## Outcome

Build execution context from the immutable Attempt and its immutable executor
RunBinding, then resolve its canonical WorkItem in the selected workspace.

## Invariants

- The Attempt, binding, WorkItem, and agent identity must agree or admission
  fails closed.
- Dispatch does not accept a second, caller-selected WorkItem ID.
- No renderer context, local path hint, or secret crosses this boundary.
