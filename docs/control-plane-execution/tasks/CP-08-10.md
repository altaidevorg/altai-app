# CP-08-10 — Durable scheduler execution snapshot

**Status:** in progress  
**Depends on:** CP-08-09

## Outcome

After scheduler ownership, read the Attempt and immutable RunBinding from the
same local `work.db` through one host-facing snapshot boundary.

## Invariants

- Missing or mismatched records fail closed.
- The loader never creates an attempt, binding, run ID, or agent identity.
- This is still local-first SQLite; it introduces no control-plane daemon or
  second Work database.
- CP-08-11 will call this loader from the scheduler-owned handoff, prepare the
  trusted admission, then start the native runtime path.
