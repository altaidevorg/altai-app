# Task Packet: CP-08-05 — Authorized Runtime Run Identity

```yaml
task_id: CP-08-05
title: Admit authorized executor runs using the immutable RunBinding ID
status: in_progress
depends_on: [CP-08-04]
```

## Outcome

The shared execution service accepts a trusted, pre-authorized run ID. The
normal chat path still allocates its own UUID; only the host-side
control-plane adapter can cause IsanAgent to admit a canonical `RunBinding` ID.

## Invariants

- A normal user chat cannot choose or replace a runtime run ID.
- An authorized run ID must be non-empty and becomes the ID in both the
  coordinator lease and the IsanAgent inbound metadata.
- Failed ingress rolls back that exact admitted lease.
- This packet does not make a WorkItem terminal and does not introduce a
  second database or scheduler.

## Follow-on

The trusted Desktop adapter will call this port only after it resolves an
authorized Attempt, its immutable RunBinding, and host execution settings.
