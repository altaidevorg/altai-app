# CP-08-11 — Bounded canonical run context

**Status:** in progress  
**Backlog package:** 031  
**Depends on:** CP-04, CP-08-10

## Outcome

Build an execution context from canonical workspace, project, goal ancestry,
and WorkItem records. It is deterministic, scope-checked, and capped at 24 KiB.

## Invariants

- A filesystem local-path hint is never context identity and is excluded.
- Cross-project or cross-organization input fails closed.
- The context is a bounded snapshot, not a renderer assembled conversation
  ferry. Repository assembly and the scheduler handoff follow in later 031
  and CP-08 slices.
