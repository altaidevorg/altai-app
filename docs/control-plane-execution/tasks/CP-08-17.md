# CP-08-17 — Explicit legacy WorkStore reconciliation

**Status:** in progress  
**Backlog package:** 031  
**Depends on:** CP-08-16

## Outcome

Allow an explicit bridge reconciliation only when the canonical WorkItem has
not changed independently since the bridge last projected it.

## Invariants

- Reconciliation uses the mapping's expected canonical revision.
- A concurrent canonical writer causes a stale-revision failure rather than an
  overwrite.
- This remains an explicit bridge operation; it does not make legacy UI code a
  hidden writer of canonical state.
