# CP-08-09 — Native authorized IsanAgent admission

**Status:** in progress  
**Depends on:** CP-08-08

## Outcome

Route a prepared `TrustedAttemptAdmission` directly to
`AgentService::route_authorized_send`.

## Invariants

- The IsanAgent run ID is the durable `RunBinding.run_id`; it is not minted by
  the runtime and is not accepted from renderer input.
- The session/chat identity comes from the canonical attempt binding.
- Provider, endpoint, permission policy, profile instructions, and API key
  come from the native admission value. API key material remains native-only.
- This is a host function, not a Tauri command. CP-08-10 will provide its
  scheduler-owned caller after attempt records can be loaded atomically.
