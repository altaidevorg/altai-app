# Task Packet: M2-01-01 — Control-plane bootstrap and host registration

task_id: M2-01-01
title: Add the control-plane crate with versioned health and one-time host registration
risk_tier: B
status: ready
depends_on: [M2-00-01]
objective: |
  Create the smallest Rust control-plane service boundary without moving any
  legacy Work mutation: validate local SQLite workspace configuration,
  expose non-secret health, issue one-time expiring registration grants, and
  register version-compatible execution hosts.

  - Network transport, daemon process supervision or database connection

  - docs/control-plane-execution/tasks/M2-01-01.md
invariants:
  - The plaintext grant is returned once and never retained.
  - A grant is one-time, expiring and consumed only after request validation.
  - The host uses canonical AgentInstanceId and WorkspaceId identities.
  - altai-agent-service must not depend on control-plane crates.
acceptance:
  - The new crate passes focused tests and clippy with warnings denied.
  - Health contains no credentials and does not claim database connectivity.
  - Incompatible host protocol and malformed store configuration are rejected.
  - Architecture tests prove the control plane is a workspace peer, not an
    execution-plane dependency.
stop_conditions:
  - A transport or persistence dependency is required to prove registration.
  - The implementation would make local work.db and the control plane write
    the same authoritative field.
