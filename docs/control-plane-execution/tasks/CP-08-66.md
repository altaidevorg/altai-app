# CP-08-66 — Measured large-graph usability (package 068 closure)

- **Package:** 068 — Canvas 2D Work board (PR 2, closing)
- **Status:** in review
- **Depends on:** 062 (board rows: #802-era), 068 PR 1 (#808)

## Outcome

The measured half of package 068's gate. PR 1 (#808) shipped the canvas
graph (pure projection + draw-only component) with the column board as
the accessible non-canvas fallback of the same rows; this PR adds the
measurement that turns "should scale" into numbers, and accepts the
package.

## What was measured

Synthetic worst-case shapes at 500 / 1 000 / 2 500 nodes — a deep chain
(one node per depth; the recursion worst case) and a fan-out tree of 5
(the tallest columns). Layout is the second call (steady state), so JIT
warm-up cannot mask a budget:

| Shape | 500 | 1 000 | 2 500 |
| --- | ---: | ---: | ---: |
| deep chain | 0.76 ms | 0.69 ms | 1.66 ms |
| fan-out tree (×5) | 0.42 ms | 0.78 ms | 1.53 ms |

Canvas area — the scroll burden — grows near-linearly: doubling the
graph (500 → 1 000 tree nodes) multiplies area by 2.19 (bound: < 2.5).
A 1 000-node malformed cycle places every node instead of hanging, and
identical rows lay out byte-identically.

The latency budget in the tests is 200 ms — ~100× the observed numbers,
chosen so CI variance cannot flake it while still failing loudly if the
layout ever turns quadratic.

## Scope

- `src/modules/work-board/lib/canvasGraphProjection.scale.test.ts`
  (new): 10 measurement tests — latency budgets per shape and size,
  determinism at 1 000, area-growth bound, cycle placement at 1 000,
  and an exactness check that the published canvas size derives from
  the columns actually built.

No production code changed: the measurement is evidence, not a fix —
nothing it measured needed one.

Honest boundary: this measures the pure projection, which is everything
the module computes. Browser-side paint cost (drawing N rounded-rects
per frame) is the component's draw loop over this layout and is not
covered by a jsdom harness; the column-board fallback carries large
boards where canvas paint is a concern.
