## Outcome

073's gate — **UI cannot bypass worker capability checks** — is met in
code and green in CI, in two halves:

- the static half (#822): a declarative surface/action schema
  (Section/Text/Table/Action, bounded) carried on the plugin manifest,
  validated at registration with the same first-error order on both
  sides of the boundary;
- the runtime half (#823): `invoke_ui_action` resolves a trigger
  against the installed declaration — the declaration is the
  whitelist — then routes through the ordinary dispatch path, so the
  capability is re-checked at the boundary (a hand-crafted manifest
  cannot bypass it) and a repeated trigger hits the at-most-once
  ledger, proven against a real worker process's request counter.

This PR records the acceptance. No code changes.
