# CP-08-90 — qm provenance and evidence/replay conformance discovery

- **Package:** 084 — qm codebase (PR 1)
- **Status:** in review
- **Depends on:** 045 (Evidence and governed delivery), 060 (Activity
  projections/replay), and CP-08-89 (preceding ordered adoption-track gate)

## Outcome

Pin the authoritative qm source and license; inspect only mechanisms relevant
to auditable work, evidence and deterministic replay; then decide whether any
bounded source adoption is safe before copying code or enabling a quality
authority. The record determines that qm is a full agent harness and direct
adoption is deferred. It specifies `QM-084-evidence-replay-v1` as an
ALTAI-native follow-up fixture.

## Scope

- Reproducible source, revision and license record.
- Explicit candidate-to-canonical-contract decision for core state, scoped
  execution, audit, replay and deployment/secret mechanisms.
- Deterministic fixture phases and negative controls grounded in Evidence
  (045) and Activity replay (060).
- No vendored source, package dependency, runtime process, identity registry,
  database, plugin, secret path or external score authority.

The source inventory, decision matrix and fixture are in
`QM_CONFORMANCE_DISCOVERY.md`.

## Acceptance

- Every inspected mechanism is mapped to a named existing ALTAI boundary or
  rejected with its authority conflict.
- The pinned revision and license are independently reproducible.
- The proposed fixture has deterministic input, replay, comparison, recovery
  and negative-control observations.
- Any follow-up is bounded to an ALTAI-native fixture; no qm runtime or source
  is approved by this discovery task.
