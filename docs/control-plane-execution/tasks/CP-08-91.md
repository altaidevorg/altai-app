# CP-08-91 — ALTAI-native qm evidence/replay conformance fixture

- **Package:** 084 — qm codebase (PR 2)
- **Status:** in progress
- **Depends on:** CP-08-90, 045 (immutable Evidence), and 060 (ordered
  Activity replay)

## Outcome

Implement `QM-084-evidence-replay-v1` using only canonical ALTAI repositories
and control-plane contracts. The fixture creates a normalized, versioned
comparison input from immutable Evidence and ordered Activity correlations;
it proves deterministic read/replay, idempotent recovery and fail-closed
negative controls without introducing a quality model or external evaluator.

## Scope

- A small ALTAI-owned normalization type and typed validation errors.
- Repository-backed fixture coverage for deterministic serialization,
  Work/Attempt/org attribution, idempotent replay and conflicting evidence.
- Explicit exclusion of timestamp, model output, wall clock, remote score,
  qm session, qm identity, qm credential and qm runtime state from the
  comparison input.
- No dashboard, scheduler, delivery mutation, completion decision or qm
  package/runtime integration.

## Acceptance

- Identical canonical Evidence/Activity reads produce byte-identical
  comparison input in their stored order.
- Cross-work, cross-attempt, cross-organization, uncorrelated and duplicate
  conflicting inputs fail typed without changing valid records.
- Reopening the repository and re-recording an identical evidence item keeps
  the normalized result unchanged.
- Focused tests, full `altai-control-plane` tests and clippy pass.
