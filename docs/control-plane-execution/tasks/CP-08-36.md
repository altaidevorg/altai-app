# CP-08-36 — Public versioned control protocol contracts and capability negotiation

**Status:** in_progress
**Backlog package:** 051 (first PR)
**Depends on:** CP-08-35 (package 050 accepted, Stage 5 started), CP-08-18/19 (package 035), CP-08-25/26 (package 042), CP-08-27/28 (package 043), CP-08-32/33 (package 044)

## Outcome

First half of the 051 gate — **"Command/query/event conformance across local and deployed transports"** — the shared protocol contracts and capability negotiation definitions. Exposes a versioned, capability-negotiated protocol contract that unifies command envelopes, cursor pagination, event replay queries, capability discovery, and typed error responses across Rust and TypeScript.

## Rationale

Prior packages built the internal domain repositories and gates (scopes, agents, work graph, wakes/leases, attempts, routines, approvals, usage, evidence, recovery, workspace scope). To fulfill CP-15 ("Expose one capability-negotiated API to every ALTAI surface"), all clients (Desktop, IDE, Studio, CLI, and future remote workers) must share one canonical protocol framing:
1. Versioned protocol specification (`ProtocolVersion`, `CONTROL_PLANE_PROTOCOL_MAJOR`).
2. Capability discovery (`ControlPlaneCapabilities`, `DeploymentMode`, `CapabilityNegotiationRequest`/`Response`).
3. Standardized cursor pagination (`PageRequest`, `PageResponse<T>`).
4. Uniform request/response framing (`ProtocolRequest<T>`, `ProtocolResponse<T>`, `ProtocolError`).
5. Event replay and activity query contracts (`EventReplayRequest`, `EventReplayResponse`, `ActivityQueryRequest`).

The second PR (CP-08-37) wires these contracts into the transport dispatcher and runs cross-transport conformance tests.

## Scope (this PR)

- `altai-control-protocol/src/protocol.rs` (new module):
  - `ProtocolVersion { major: u16, minor: u16 }`
  - `ControlPlaneCapabilities` struct with standard capability flags: `organizations`, `goals`, `projects`, `workspaces`, `agents`, `work_graph`, `attempts`, `routines`, `approvals`, `budgets`, `evidence`, `activity_audit`, `event_replay`, `workspace_scopes`.
  - `DeploymentMode`: `LocalDaemon`, `DeployedBackend`, `EmbeddedHost`.
  - `CapabilityNegotiationRequest` / `CapabilityNegotiationResponse`.
  - `PageRequest { cursor: Option<String>, limit: u32 }` with bounded limits (default 50, max 250).
  - `PageResponse<T> { items: Vec<T>, next_cursor: Option<String>, has_more: bool, total_count: Option<u64> }`.
  - `ProtocolRequest<T>` & `ProtocolResponse<T>`.
  - `ProtocolError { code: ControlErrorCode, message: String, data: Option<serde_json::Value> }`.
  - `EventReplayRequest`, `EventReplayResponse`, `ActivityQueryRequest`.
- Protocol re-exports in `altai-control-protocol/src/lib.rs`.
- Fix unused variable in `altai-control-protocol/src/event.rs`.
- Corresponding TypeScript contracts in `packages/control-contract/src/protocol.ts` and `packages/control-contract/src/index.ts`.
- Rust unit tests in `altai-control-protocol` and TypeScript unit tests in `packages/control-contract/src/__tests__/protocol.test.ts`.

## Out of scope (follow-up PRs)

- Protocol dispatcher and route registration in `altai-control-plane` (051 PR 2).
- Migration runner and lifecycle (package 052).
- Host adapters (package 053).

## Invariants

- Protocol errors always preserve typed `ControlErrorCode`.
- Capability negotiation accurately reflects supported features without guessing.
- Pagination bounds (limit max 250) fail-safe to valid bounds.
- Rust and TypeScript protocol structures serialize and deserialize with compatible JSON shapes.
