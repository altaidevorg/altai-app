# CP-08-15 — Durable native admission input

**Status:** in progress  
**Backlog package:** 031  
**Depends on:** CP-08-08, CP-08-10, CP-08-13, CP-08-14

## Outcome

Let native attempt admission accept only a workspace ID and Attempt ID, then
derive the immutable execution snapshot and bounded canonical context from
local `work.db` repositories.

## Invariants

- Renderer-owned context text and a caller-selected WorkItem ID are absent
  from the durable admission path.
- Attempt/RunBinding validation happens before context construction.
- OS-secret and provider profile resolution remain native-only and unchanged.
