# CP-08-60 — Canvas 2D Work board

- **Package:** 068 — Canvas 2D Work board (PR 1)
- **Status:** in review
- **Depends on:** 062

## Outcome

The Work board's rows can now be read as a 2D spatial graph. A
`Board | Graph` toggle in the board header switches between the column
board (default, keyboard-accessible) and a canvas rendering of the same
rows: one column per parent-chain depth, deterministic stacking within
a column, and bezier edges from each parent to its children. Clicking a
node opens that Work, exactly like clicking a card in the column view.

## Rationale

Package 068's gate asks for a canvas board whose large-graph usability
is measured and whose non-canvas fallback stays accessible. The rows
the board already renders (package 062) carry everything the graph
needs — including `parentWorkId`, which was present on the wire
(`WorkItemDto.parent_work_id`) but dropped by the board projection —
so the canvas needs no new backend surface, only spatial arrangement.

That arrangement is geometry, so it lives in a pure, tested projection
(`canvasGraphProjection.ts`): depth by parent chain with a cycle-safe
resolver, columns per depth, stable (title, id) ordering, and edge
paths. The component (`WorkCanvasBoard`) only draws the layout
(DPR-aware) and hit-tests clicks; it computes nothing. The column board
stays the default view, so the accessible fallback is not a separate
implementation to keep in sync — it is the same rows, one toggle away,
and the canvas carries an aria-label that names the switch.

## Scope

- `src/modules/work-board/lib/canvasGraphProjection.ts` (new): the
  layered layout (`layoutWorkGraph`), node/edge/layout types, shared
  size constants, title anchor helper.
- `src/modules/work-board/lib/canvasGraphProjection.test.ts` (new):
  depths (roots, chains, deepest chain), off-board parents, column
  ordering and spacing, edge geometry, canvas sizing, empty board,
  cycle safety, title anchor.
- `src/modules/work-board/WorkCanvasBoard.tsx` (new): DPR-aware canvas
  draw, pointer hover + click hit-test, `role="img"` label.
- `src/modules/work-board/WorkBoard.tsx`: `Board | Graph` view state
  with segmented toggle; the graph branch renders the canvas for the
  same rows; loading/error/empty states stay shared.
- `src/modules/work-board/lib/workBoardProjection.ts`:
  `WorkBoardRow` gains `parentWorkId` (threaded from
  `WorkItem.parentWorkId`).
- `src/modules/work-board/index.ts`: exports.

## Out of scope

- Large-graph **measurement** (the gate's first half): interaction
  telemetry, viewport fitting/zoom, and virtualization for very wide
  graphs — package 068 PR 2.
- Graph editing (drag-to-reparent), edge routing beyond the simple
  bezier, minimap.
- The Work-detail graph slice (`WorkGraphSection`) stays the focused
  structural view; this board graph is the workspace-wide view.
