# CP-08-52 — Runs hub: the workspace's recent attempts, one projection

**Status:** complete
**Backlog package:** 063 (Runs hub and Run Inspector) — PR 2 of 2–3
**Depends on:** CP-08-51 (timeline + `work_events` read side), package 060
(read-model projections)

## Outcome

Home now has a Runs hub. Under the Inbox in Home's left column, the
workspace's most recently updated attempts render as rows — work title,
attempt number, the Work's status, a phase dot, and a relative time — and
each row opens its Work detail, where the timeline from PR 1 lives. A
workspace with no runs renders no hub section at all.

The hub's data comes from one server projection: `work_runs`, backed by
`WorkStore::list_recent_attempts` — attempts joined with their Work in a
single query, newest first, bounded (default 20, capped at 100). No
per-Work fan-out, honoring package 060's rule that server projections
answer operational queries.

## Rationale

Package 062's gate carries into the hub: each row exposes the Work's
`status: WorkState` and the attempt's `phase: WorkAttemptPhase` as
distinct typed fields — a succeeded attempt on in-review Work shows both
facts, never one folded label. The hub is the cross-Work complement to
the detail surface: the detail inspects one Work's runs, the hub answers
"what has been executing across the workspace?".

Failures degrade: a failed `work_runs` call leaves the previous page in
place rather than failing Home — the hub is an addition to Home's
refresh, not a dependency of it.

## Scope

- `altai-core work.rs`: `RecentAttemptRecord` (attempt + `work_title` +
  `work_state`) and `WorkStore::list_recent_attempts(limit)` — a single
  JOIN, newest first; exported from the crate.
- `src-tauri/modules/work.rs`: `WorkRunDto` + `work_runs` command
  (limit optional, default 20, capped at 100); registered in `lib.rs`.
- `packages/host-contract`: `WorkRun` type.
- `native.ts`: `workRuns(limit?, workspacePath?)`.
- `runsHubProjection.ts`: `projectRunsHub` / `toWorkRunRow` — distinct
  status/phase axes, server order preserved.
- `RunsHubSection.tsx`: accessible list; phase dot (board's palette);
  renders nothing when empty.
- `DesktopHome.tsx`: left column becomes a stack — Inbox (flex) above,
  Runs hub (bounded, own scroll) below; runs load in Home's existing
  refresh cycle.
- `WORK_OS_PROGRAM_BACKLOG.md`: queue advances to CP-08-53 (063 PR 3).

## Out of scope

- Transcript, approvals, evidence and delivery inspection — CP-08-53,
  scoped to the slices that have producers.
- A dedicated Runs destination in the desktop nav — destinations stay
  `home | work | agents`; replacing the legacy `work` destination remains
  a cutover (package 101).
- Paging beyond the first bounded page — the hub is a recent-runs strip,
  not a searchable archive.
