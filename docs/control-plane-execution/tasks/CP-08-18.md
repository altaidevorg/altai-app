# CP-08-18 — Attempt finalization from run termination

**Status:** in progress  
**Backlog package:** 035  
**Depends on:** CP-08-02

## Outcome

Translate an observed executor run termination into exactly one durable Attempt
terminal transition. The finalized Attempt is the verification signal; finalization
never completes or mutates the bound WorkItem.

## Rationale

The Attempt lifecycle reaches `Running`, but nothing closes the loop when the
IsanAgent run terminates. `AttemptRepository::transition` already enforces a
valid, idempotent state machine; this package supplies the missing
outcome→state translation so a completed run finalizes the Attempt instead of
leaving it permanently `Running`.

## Invariants

- Each `RunOutcome` variant maps to exactly one terminal `AttemptState`; there
  is no unknown outcome path.
- Replaying the same completion is an idempotent no-op: the attempt is returned
  unchanged, never re-transitioned, never an error.
- A divergent observation after the attempt is already terminal fails closed as
  `AlreadyTerminal` — first terminal observation wins, no state change.
- The observed run-completion time becomes the Attempt `updated_at`, replacing
  any caller-invented "now".
- Finalization depends only on `AttemptRepository`; it has no handle to any
  WorkItem repository and therefore cannot complete Work by construction.
