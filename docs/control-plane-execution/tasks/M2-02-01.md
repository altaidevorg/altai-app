# Task Packet: M2-02-01 — Authenticated loopback daemon transport

```yaml
task_id: M2-02-01
title: Run the bootstrap control plane behind authenticated versioned loopback HTTP
risk_tier: B
status: ready
depends_on: [M2-01-01]
objective: |
  Add an independently runnable altai-control-plane binary with only three
  initial routes: authenticated health, authenticated one-time grant issuance,
  and grant-authenticated host registration.
non_goals:
  - Public/deployed listener, TLS termination or reverse proxy
  - Control database connection/migration
  - Work dispatch, synchronization or local work.db migration
allowed_files:
  - src-tauri/Cargo.lock
  - src-tauri/crates/altai-control-plane/
  - docs/control-plane-execution/tasks/M2-02-01.md
invariants:
  - Daemon binds loopback only.
  - Bootstrap bearer token is at least 16 bytes, is hashed in memory, and is
    never written to logs/errors.
  - Grant tokens are one-time and are never a substitute for bootstrap access.
  - Health response exposes no credential or connection string.
acceptance:
  - HTTP tests prove health rejects missing bearer and a granted host registers.
  - Binary help/config describes loopback-only behavior.
  - Focused tests and clippy warnings-denied pass.
stop_conditions:
  - A public listener is needed before TLS/auth deployment semantics are defined.
  - A route needs an authoritative Work field or database state.
```
