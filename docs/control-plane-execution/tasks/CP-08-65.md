## Gate evidence

The gate reads: *idempotent sync, explicit authority and conflict
resolution.*

- **Idempotent sync** — the store keys objects by the provider's
  immutable identity `(integration, external_id)` and treats an equal
  `content_hash` as a no-op (#809); the engine hashes canonical mapped
  content and never writes or emits for an unchanged payload, with the
  `since` watermark on the provider's clock (#810).
- **Explicit authority** — per-object `ExternalAuthority`: the provider
  wins or the local side wins, decided by the recorded rule and never by
  write order (#809, #810).
- **Conflict resolution** — a refused overwrite records both hashes;
  `take_external` flips authority so the next sync applies, `keep_local`
  dismisses exactly the refused content, and every decision is an
  audited activity event (#812).
- **Adapter** — the GitHub issues provider over the desktop client
  (#811) proves the provider seam with a real integration.
