# CP-08-07 — Durable execution-profile authorization

**Status:** in progress  
**Depends on:** CP-08-06

## Outcome

Resolve the profile used for a dispatched attempt from the immutable profile
revision in `work.db`, after confirming that its owner agent is active and owns
the same revision. The webview never supplies the model or profile revision.

## Boundaries

- This reads the existing local `work.db`; it introduces no daemon, second
  database, Postgres, or synchronization layer.
- Credential resolution remains the host-only CP-08-06 step. This record holds
  provider/model policy, never a credential value.
- The following milestone will compose this authorization with the trusted
  profile resolver and call the authorized IsanAgent admission port.
