# CP-08-08 — Host-only trusted attempt admission

**Status:** in progress  
**Depends on:** CP-08-05, CP-08-06, CP-08-07

## Outcome

Compose attempt/run/session binding validation, durable active-agent profile
authorization, and OS-backed credential resolution into one native-only value.

## Invariants

- Renderer input cannot choose a provider, model, endpoint, profile revision,
  or credential.
- The credential-bearing value is not serializable and is never exposed by a
  Tauri command.
- The next milestone wires this prepared admission to
  `AgentService::route_authorized_send` using the immutable `run_id`.
