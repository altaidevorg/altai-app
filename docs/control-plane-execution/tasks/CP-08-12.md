# CP-08-12 — Durable canonical WorkItem source

**Status:** in progress  
**Backlog package:** 031  
**Depends on:** CP-04, CP-06, CP-08-11

## Outcome

Persist and read canonical typed WorkItem records from the existing local
`work.db`, scoped to their canonical Project ID.

## Invariants

- This does not replace the existing WorkStore attempt ledger or copy its
  lifecycle fields. A later explicit bridge maps records under one writer.
- Missing and cross-project reads fail closed.
- Context assembly can now read both scope and WorkItem through typed
  repositories rather than accepting renderer-provided work text.
