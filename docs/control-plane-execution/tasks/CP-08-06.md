# Task Packet: CP-08-06 — Trusted Execution Profile Resolution

```yaml
task_id: CP-08-06
title: Resolve managed execution profiles and credentials host-side
status: in_progress
depends_on: [CP-08-05]
```

## Outcome

An authorized attempt resolves its immutable `provider/model` profile only in
the Desktop host. The host reads its provider credential from the existing
OS-backed `altai-ai` secret store; no raw credential or endpoint is accepted
from a webview command.

## Initial scope

- Managed cloud providers only, with canonical HTTPS routes.
- Local/custom-compatible endpoints are deliberately rejected until profile
  revisions contain an immutable endpoint and credential-reference contract.
- Permission policy is validated against the existing host modes.
